# Ethevex

A domain that encompasses all

Ethevex is an independent software initiative focused on building developer tools, applications, and open-source projects. Driven by curiosity, experimentation, and a commitment to thoughtful engineering.

[ethevex.com](https://ethevex.com) · [GitHub](https://github.com/Ethevex) · [Creator](https://github.com/DavidAsrorxonov)

Built with Next.js, TypeScript, Tailwind CSS, shadcn/ui, and vGPU.

## Run locally

```bash
npm ci
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
